# AGENTS Guide

## Commit messages

- Keep subject <=50 chars including spaces.
- Use imperative mood: `add`, `fix`, `update`, `refactor`.
- No period at end.
- Example: `add film camera easing`
- Validation: `python3 scripts/validate.py` must pass.
- Hook: `.git/hooks/commit-msg` checks length, rejects >50.

## Comments

- Each comment must be single line only.
- No `/* ... */` spanning multiple lines.
- Header block at top of file max 4 lines.
- Avoid restating code; explain why, not what.
- Validation: same `scripts/validate.py` checks header count and block span.
- Hook: `.git/hooks/pre-commit` runs validation.

## Workflow

- Run `npm run validate` before commit.
- Run `npm run ci` for the whole local gate: validate, lint, format, check, build, test.
- CI (`.github/workflows/ci.yml`) runs validate, build, checks, tests, eval.
- `scripts/ci_watch.py watch` pools GitHub CI until it finishes.

## Architecture

- Svelte 5 runes (`$state`, `$derived`, `$effect`, `$props`); actions for DOM.
- Hash router in `src/lib/router.svelte.ts`; routes: home, releases, support.
- Styling: tokens and components in `src/app.css`; tailwind import for utilities.
- Film camera damps toward scene focus rects in `src/lib/scenes.ts`.
- Downloads: `platform.ts` detects OS/arch, `downloads.ts` maps the matrix.
- Support: `wallets.ts` is the chain registry; add a chain by appending there.
- EVM chains share one address; the picker swaps explorer and QR mark only.
- Local Myanmar methods live in `myanmar.ts`, mocked until the owner goes live.
- Release notes are generated by `npm run releases`; never hand edit data.ts.
- Theme: `stores/theme.svelte.ts`, `.dark` on html, tokens flip in `app.css`.

## Tests and captures

- Playwright config pins `workers: 1`; headless shell SEGVs under memory pressure.
- Never screenshot Home with `fullPage: true`; capture viewport beats instead.
- After viewport or scroll jumps, wait ~1.5s for the camera to settle.
- Behaviour specs assert platform picks, QR counts, flip and theme persistence.

## Push

- Only push after CI passes locally.
- Force push to `main` replaces upstream.

## Commands

- `npm run dev` — dev server
- `npm run preview` — serve the production bundle
- `npm run build` — production bundle
- `npm run validate` — commit and comment gate
- `npm run test` — playwright behaviour plus captures
- `npm run screenshots` — captures only
- `python3 scripts/eval.py` — self review report
